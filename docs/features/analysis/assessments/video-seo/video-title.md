The **Video title** assessment checks whether the SEO title contains the word "video". It is part of the SEO analysis of [Yoast Video SEO](https://yoast.com/product/video-seo-wordpress/).

| **Video title** | |
|---|---|
| **Name in code** | `VideoTitleAssessment` |
| **Title URL** | None |
| **Call to action URL** | None |
| **When it applies** | Always. |
| **Product** | Yoast Video SEO |
| **Content types** | Content types where Yoast Video SEO is active |
| **Related keyphrases** | ❌ |
| **Uses synonyms** | ❌ |
| **Languages** | All languages |
| **Cornerstone** | ❌ Same scoring |
| **Uses highlighting** | ❌ |
| **Uses morphology (Premium)** | ❌ |

## Scoring

| Traffic light | Score | Criterion | Feedback |
|---|---|---|---|
| Orange | 6 | The SEO title does not contain the word "video" | You should consider adding the word "video" in your title, to optimize your ability to be found by people searching for video. |
| Green | 9 | The SEO title contains the word "video" | You're using the word "video" in your title, this optimizes your ability to be found by people searching for video. |
