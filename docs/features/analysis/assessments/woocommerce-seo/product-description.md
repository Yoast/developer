The **Product description** assessment checks the length of the product short description on WooCommerce product pages. It is part of the SEO analysis of [Yoast WooCommerce SEO](https://yoast.com/product/yoast-woocommerce-seo/).

| **Product description** | |
|---|---|
| **Name in code** | `ProductDescriptionAssessment` |
| **Title URL** | None |
| **Call to action URL** | None |
| **When it applies** | Always, on WooCommerce product pages. |
| **Product** | Yoast WooCommerce SEO |
| **Content types** | WooCommerce product pages |
| **Related keyphrases** | ❌ |
| **Uses synonyms** | ❌ |
| **Languages** | Japanese counts characters instead of words, with different boundaries (see the scoring table). |
| **Cornerstone** | ❌ Same scoring |
| **Uses highlighting** | ❌ |
| **Uses morphology (Premium)** | ❌ |

## Scoring

| Traffic light | Score | Criterion | Feedback |
|---|---|---|---|
| Red | 1 | The short description is empty (0 words) | You should write a short description for this product. |
| Orange | 5 | Fewer than 20 words (Japanese: 40 characters) | The short description for this product is too short. |
| Green | 9 | Between 20 and 50 words (Japanese: 40 and 100 characters) | Your short description has a good length. |
| Orange | 5 | More than 50 words (Japanese: 100 characters) | The short description for this product is too long. |
