This page will describe the `Yoast-User` user agent: what it requests and how to control it with robots.txt.

## Yoast-User {#yoast-user}
For requests a Yoast service makes because someone asked for them, rather than a crawl of Yoast's own. The description of what it requests is being written.

## Yoast-Scout {#yoast-scout}
Reserved for a crawler of Yoast's own. Not in use: no Yoast service sends this user agent.
