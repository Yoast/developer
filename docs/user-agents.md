This page will list the user agents Yoast's services send to websites, what they request, and how to control them with robots.txt.

## Yoast-User {#yoast-user}
The user agent of requests Yoast makes because a customer asked for them. The description of what it requests is being written.

## Yoast-Scout {#yoast-scout}
Reserved for a crawler of Yoast's own. Not in use: no Yoast service sends this user agent.
